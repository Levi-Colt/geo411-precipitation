# geo411-precipitation
R analysis of precipitation data for Buffalo and San Diego

GEO 411 HW 1

Overview: This assignment analyzed annual precipitation data for Buffalo and San Diego between 1940 and 2025. Using R, a csv file containg the data was loaded and read, summary statistics, means, and standard deviations were calculated, histograms were plotted, subsets of the dataset were created, t tests were conducted, and probabilites were calculated for certain preipitation totals.

Methods: This assignment used a variety of R methods, including: dim, length, summary, mean, sd, hist, dnorm, pnrom, pbinom, sum, ifelse, and t.test.

Key Findings: While precipation patterns in Buffalo were mostly normally distributed, precipitation patterns in San Diego were right skewed. 

Tools: RStudio, Class Instruction

Reflection: The skewed precipitation data for San Diego suggests that the higher observed precipitation totals are likely the result of abnormal weather events.
